## 账号级补充模板

账号报告先给样本表：发布时间、时长、题材、形式、赞藏评享、相对粉丝表现、成熟度和证据完整度。随后输出：

1. 内容支柱与各自作用（扩散/收藏/转化/人设）
2. 高传播样本与普通样本对照
3. 可重复规律、相反样本和证据边界
4. 人设、听觉/视觉品牌和内容承诺
5. 更新与系列化方式
6. 1–2 条代表作的完整单条模板
7. 给 AI 编导的选题矩阵、生产规则和测试路线

不能从一个孤立爆款推导稳定账号规律。

## 交付自检

- [ ] 样本被正确标为明确爆款、潜力款或对照样本。
- [ ] 事实、传播假设、编导判断、待验证项已区分。
- [ ] 目标观众具体到任务和认知阶段。
- [ ] 钩子包含首帧、首句、未闭合问题、首次兑现。
- [ ] 时间轴包含内容功能、情绪/证据、留存和流失风险。
- [ ] 剪辑、信息、叙事三种节奏分别判断。
- [ ] 主要主张都有证据强度和缺口。
- [ ] CTA 写清交换关系。
- [ ] 可复用、需重做、不可复用边界明确。
- [ ] 改编方案包含可拍骨架、素材、表演/剪辑和验收点。
- [ ] 测试计划一次只改一个主要变量。
- [ ] 无账号上下文时未强行声称“适合你的成稿”。
- [ ] 完整短视频拆解已读转写和全部 contact sheet，末尾附原始转写。
- [ ] 报告已存档，且未包含敏感凭证或私人信息。
